# Sobre o projeto
Os codigos dessa pasta foram desenvolvidos para realização de interpolação de splines cubicas utilizando definições de analise numérica.

## Estrutura dos arquivos
- `exercicio.ipynb`: Notebook Jupyter contendo a resolução dos exercícios propostos.
- `spline.py`: Módulo Python contendo a implementação da interpolação por splines cúbicas.
- `utils.py`: Módulo Python com funções utilitárias para auxiliar na resolução dos exercícios.

## Como executar
1. Certifique-se de ter o Python instalado em sua máquina.
2. Instale as dependências necessárias, se houver. Lista de dependências:
   - numpy
   - sympy
3. Abra o notebook `exercicio.ipynb` em um ambiente Jupyter.
4. Execute as células do notebook para ver os resultados da interpolação por splines cúbicas.
